縦書き小説チェックツール

タイトル・著者名を入力すると、縦書きプレビューの一番右（先頭）に大きめの文字で表示されます（どちらも空欄なら表示されません）。テキスト・HTML出力や印刷にも反映されます。

同人誌サイズ: 選択すると「1行の文字数」を判型ごとの目安に自動設定します。フォントサイズや余白で最適な字数は変わるため、あくまで目安です。「1行の文字数」を直接編集すると自動的に「カスタム」に戻ります。

字下げ: チェックを入れると、「」『』（）で始まらない段落の先頭に全角スペースを1つ入れて1字下げします。空行や、すでに空白で始まっている行はそのままです。縦書きプレビューだけでなく、コピー用テキスト・テキストダウンロードにも反映されます。

ルビ: 「本気《マジ》」のように漢字の直後に《よみ》を付けるか、「｜任意の語句《よみ》」のように｜（全角縦棒）で始まりを指定できます（青空文庫形式）。「[[rb:語句>よみ]]」（pixiv形式）も入力として認識します。「ルビの出力形式」で選んだ形式に、コピー用テキスト・テキストダウンロードのルビ表記がすべて揃えられます。

強調（傍点）: 「[[強調したい文字列]]」のように二重角括弧で囲むと、縦書きプレビューで文字の右側に傍点が付きます。日本語入力で全角になった「［［強調したい文字列］］」でも認識します。

濁点の強制付与: 「{{あ}}」のように二重波括弧で囲むと、「あ゙」のように本来濁点が付かない文字にも濁点を付けられます（叫び声などの表現用）。全角「｛｛｝｝」でも認識します。

2段組み: 列をA4用紙1ページ分の幅ごとに上下2段へ分けて、本のページのように表示・印刷します。「1段の列数」を指定すると、自動計算の代わりにその列数ごとに次の段へ進みます（空欄なら自動）。

ページ数の目安: 1段組みのとき「1ページの行数」を指定すると、本文の列数（空行も1行として数えます）から大体のページ数を下の文字数欄に表示します（タイトル・著者名は含みません）。2段組みのときは、プレビューのページ数をそのまま表示します。

原稿ファイルと同期: VS Code の Live Preview などローカルサーバー経由で開いているとき、「原稿」で選んだファイルを約1秒ごとに読み込み、変更があれば入力欄へ自動で流し込みます。選べるのは、このフォルダの「原稿.txt」と「原稿」フォルダ内の .txt ファイルです（章ごとにファイルを分けたいときは「原稿」フォルダに置いてください）。同期中は入力欄を直接編集できません（選んだファイル側を編集・保存してください）。「書いている箇所へプレビューを自動で移動する」にチェックを入れると、原稿の変更を検知するたびに、変更された箇所が見える位置まで縦書きプレビューをスクロールします。ファイルを直接開いた場合（file://）は使えません。

入力内容と各設定は、このブラウザ内（localStorage）に自動保存されます。ページを再読み込みしても消えません（他の端末やサーバーには送信されません）。
