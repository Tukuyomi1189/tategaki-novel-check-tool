縦書き小説チェックツール

設定
使い方の説明
タイトル・著者名

タイトル・著者名を入力すると、縦書きプレビューの一番右（先頭）に大きめの文字で表示されます（どちらも空欄なら表示されません）。テキスト・HTML出力や印刷にも反映されます。

同人誌サイズ

選択すると「1行の文字数」を判型ごとの目安に自動設定します。フォントサイズや余白で最適な字数は変わるため、あくまで目安です。「1行の文字数」を直接編集すると自動的に「カスタム」に戻ります。

字下げ

チェックを入れると、「」『』（）で始まらない段落の先頭に全角スペースを1つ入れて1字下げします。空行や、すでに空白で始まっている行はそのままです。縦書きプレビューだけでなく、コピー用テキスト・テキストダウンロードにも反映されます。

ルビ

「本気《マジ》」のように漢字の直後に《よみ》を付けるか、「｜任意の語句《よみ》」のように｜（全角縦棒）で始まりを指定できます（青空文庫形式）。「[[rb:語句>よみ]]」（pixiv形式）も入力として認識します。「ルビの出力形式」で選んだ形式に、コピー用テキスト・テキストダウンロードのルビ表記がすべて揃えられます。

強調（傍点）

「[[強調したい文字列]]」のように二重角括弧で囲むと、縦書きプレビューで文字の右側に傍点が付きます。日本語入力で全角になった「［［強調したい文字列］］」でも認識します。

濁点の強制付与

「{{あ}}」のように二重波括弧で囲むと、「あ゙」のように本来濁点が付かない文字にも濁点を付けられます（叫び声などの表現用）。全角「｛｛｝｝」でも認識します。また「濁点・半濁点を直前の文字に結合する」が ON なら、日本語入力で打った「あ゛」「う゜」や半角の「ｱﾞ」も、記法なしで1文字分の「あ゙」「う゚」「ア゙」に変換します（「か゛」→「が」のように、通常の濁音・半濁音になる組み合わせはその文字に置き換えます）。

数字の縦中横

「数字を漢数字に変換する」を外して算用数字のまま書くとき、半角数字の1〜2桁（「23時」の「23」など）を1マスに収めて縦向きに表示します。3桁以上は横倒しのままです。プレビュー上の表示のみで、コピー用テキストは変わりません。

禁則処理

列の先頭に「。」「」」「っ」「ー」などが、列の末尾に「「」「（」などが来ないように折り返し位置を調整します。「、」「。」は1文字だけ列の下にはみ出させ（ぶら下げ）、それ以外は前の列の文字を次の列へ送ります（追い出し）。「……」「――」の2連と縦中横の「!!」などは途中で分割しません。プレビュー上の折り返しのみに影響し、コピー用テキストは変わりません。

改ページ

「［＃改ページ］」（青空文庫）または「[newpage]」（pixiv）だけを書いた行で、次のページから始めます。2段組み・印刷では次のページへ送り、1段組みのプレビューでは区切り線を表示します。コピー用テキストとテキストダウンロードでは「ルビの出力形式」に合わせた記法に揃えます。

2段組み

列をA4用紙1ページ分の幅ごとに上下2段へ分けて、本のページのように表示・印刷します。「1段の列数」を指定すると、自動計算の代わりにその列数ごとに次の段へ進みます（空欄なら自動）。

文字の大きさ調整

「プレビューの文字の大きさを欄の高さに合わせる」を ON にすると、1列（「1行の文字数」＋ぶら下げ分の1字）がプレビュー欄の高さにちょうど収まるよう、縦書きプレビューの文字を小さくします（通常より大きくはしません）。縦にスクロールしなくても列の最後まで読めるようになります。2段組み・ページ枠のときは、ページの枠ごと収まる大きさにします。スマホなど幅の狭い画面では、最初から ON になっています。プレビュー欄の大きさを変えると自動で計算し直します。画面のプレビューだけの調整で、HTML保存・PDF印刷の文字の大きさは変わりません。

1段組みのページ枠

1段組みのとき、「1ページの行数」ごとに列を区切って本のページのような枠で表示・印刷します（「1ページの行数」が空欄のときは使えません）。タイトル・著者名は1ページ目の先頭の列として数えます。

ページ数の目安

1段組みのとき「1ページの行数」を指定すると、本文の列数（空行も1行として数えます）から大体のページ数を下の文字数欄に表示します（タイトル・著者名は含みません）。2段組みのときは、プレビューのページ数をそのまま表示します。

PDF印刷の用紙

「A4」以外を選ぶと、「PDFとして印刷」をその判型の用紙サイズ（文庫 105×148mm、新書 103×182mm、A5 148×210mm、B6 128×182mm、B5 182×257mm）で出力します。1列に「1行の文字数」＋1字（ぶら下げ分）が収まるよう文字の大きさを自動で決め、1ページの列数が決まっているとき（1段組みのページ枠・2段組みの「1段の列数」）は横幅にも収まるよう調整します。「同人誌サイズ」の選択とは独立しているので、「1行の文字数」を自由に変えても用紙は変わりません。

原稿ファイルと同期

VS Code の Live Preview などローカルサーバー経由で開いているとき、「原稿」で選んだファイルを約1秒ごとに読み込み、変更があれば入力欄へ自動で流し込みます。選べるのは、このフォルダの「原稿.txt」と「原稿」フォルダ内の .txt ファイルです（章ごとにファイルを分けたいときは「原稿」フォルダに置いてください）。同期中は入力欄を直接編集できません（選んだファイル側を編集・保存してください）。「書いている箇所へプレビューを自動で移動する」にチェックを入れると、原稿の変更を検知するたびに、変更された箇所が見える位置まで縦書きプレビューをスクロールします。ファイルを直接開いた場合（file://）は使えません。

自動保存

入力内容と各設定は、このブラウザ内（localStorage）に自動保存されます。ページを再読み込みしても消えません（他の端末やサーバーには送信されません）。
