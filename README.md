# 縦書き小説チェックツール

横書きで書いた小説のテキストを、縦書きでどう見えるかブラウザ上でプレビューできるツールです。サーバー不要、`index.html` を開くだけで使えます。

**ブラウザからすぐ使う（ダウンロード不要）**: https://tukuyomi1189.github.io/tategaki-novel-check-tool/

## 使い方

上記のURLをブラウザで開くか、`index.html` をダウンロードしてダブルクリックで開いてください（Chrome / Edge / Firefox / Safari 推奨）。

画面構成は次の3つです。

- **入力（横書き）**: ここに原稿を貼り付けます。「一括削除」ボタンで入力内容をまとめて消せます（誤操作防止のため、削除前に確認ダイアログが1回表示されます）
- **コピー用テキスト**: 記号・数字変換のみを適用したテキスト。改行は増やしていないので、そのままカクヨムや小説家になろうなどに貼り付けられます。「クリップボードにコピー」ボタンで一括コピーできます
- **縦書きプレビュー**: 実際に縦書きで表示した見た目を確認できます

入力内容と各種設定（1行の文字数・チェックボックスの状態など）は、ブラウザのlocalStorageに自動保存されます。ページを再読み込みしても消えず、続きから再開できます（他の端末やサーバーには送信されません。localStorageが使えない環境では保存されず、以前と同じ挙動になります）。

入力欄を編集すると、他の2つは自動的に更新されます（少し間を置いて反映されます）。

設定欄の下の「使い方の説明」には、各機能の説明をまとめています。既定では閉じていて、開くと機能名の一覧が並び、知りたい項目だけを開いて読めます（全体の開閉状態はブラウザに保存されます）。

## 機能

### 1行の文字数

画面上部の「1行の文字数」で、縦書きプレビューが何文字ごとに次の列へ折り返すかを指定できます。原稿の改行（段落）はそのまま尊重され、段落の途中から次の段落を詰めて数えることはありません。

コピー用テキストのほうには、この折り返しによる改行は挿入されません（挿入すると原稿が壊れてしまうため）。あくまでプレビュー専用の見た目上の折り返しです。

「同人誌サイズ」のプルダウンから判型を選ぶと、「1行の文字数」を判型ごとの目安に自動設定できます。

| 判型 | 目安の文字数 |
|---|---|
| 文庫サイズ（A6） | 40字 |
| 新書サイズ | 42字 |
| A5判 | 44字 |
| B6判 | 40字 |
| B5判 | 48字 |

これらはフォントサイズや余白によって変わるため、あくまで目安です。「1行の文字数」を直接編集すると、選択は自動的に「カスタム」に戻ります。

### 禁則処理

チェックボックスで ON/OFF できます（既定は ON）。「1行の文字数」による折り返しで、列の先頭・末尾に来てはいけない文字が来ないよう、折り返し位置を調整します。

| 種類 | 対象の文字 | 処理 |
|---|---|---|
| ぶら下げ | `、` `。` `，` `．` | 列に入りきらないとき、その1文字だけ列の下にはみ出させます（1列が「1行の文字数」＋1字になります） |
| 行頭禁則 | 閉じ括弧 `」』）】〕〉》` など、`！？・：；…‥〜`、長音記号 `ー`、繰り返し記号 `ゝゞヽヾ々`、小書き仮名 `ぁぃぅぇぉっゃゅょゎ` `ァィゥェォッャュョヮヵヶ` など | 前の列の末尾の文字を道連れにして、次の列へ送ります（追い出し） |
| 行末禁則 | 開き括弧 `「『（【〔〈《` など | その文字を次の列へ送ります（追い出し） |
| 分割禁止 | `……` `――` の2連、縦中横の `!!` `!?` `?!` と数字、連続した数字（`2026` など）、濁点を結合した文字（`あ゙` など） | 途中で列を分けません |

- 「。」」のように句読点の直後に閉じ括弧が続く場合は、ぶら下げではなく追い出しで処理します（ぶら下げても次の列が「」」で始まってしまうため）
- 追い出しは最大5文字までです。「ーーーー…」のように禁則文字が長く続いて解決できない場合は、禁則を諦めて「1行の文字数」どおりに折り返します
- 縦書きプレビュー・2段組み・ページ数の目安・「テキストとしてダウンロード」の改行位置に反映されます。コピー用テキストには影響しません
- 縦中横で1マスに収まる `!!` `!?` `?!` は、文字数カウントでも1文字（1マス）として数えます

### タイトル・著者名

画面上部の「タイトル」「著者名」に入力すると、縦書きプレビューの一番右（＝読み始めの先頭）に、タイトルは大きめの太字、著者名はその左に少し小さめの文字で表示されます。書籍の扉ページのような見た目になります。

- どちらも空欄の場合は何も表示されません（任意入力）
- 感嘆符・数字・ハイフンの変換はタイトル・著者名にも適用されます
- 「テキストとしてダウンロード」「HTMLとして保存」「PDFとして印刷」のいずれにも反映されます
- 2段組み表示・印刷時も、タイトル・著者名は常に一番最初（1ページ目の先頭）に配置されます

### 感嘆符・疑問符の変換

チェックボックスで ON/OFF できます。

| 変換前 | 変換後 |
|---|---|
| ！！ | !! |
| ？？ | ⁇ |
| ！？ | !? |
| ？！ | ?! |

全角のまま縦書きにすると1文字ずつ縦に間延びして見えるため、半角2文字に変換したうえで縦書きプレビューでは「縦中横」（1マスに収める表示）にしています。

「！！！」のように3文字以上連続する場合は、先頭から2文字ずつ区切って判定します（`！！！`→`!!！`）。詳しくは[既知の制限](#既知の制限)を参照してください。

スマホの絵文字入力などで「‼️」のような絵文字由来の記号を使うと、見た目には見えない「異体字セレクター」という制御文字が一緒に入ってしまうことがあります。この文字はコピー先のフォントによっては□（豆腐文字）として表示されてしまうため、本ツールでは変換時に自動的に取り除いています。

### 半角アルファベットの表示

「BBQ」「OK」のような半角アルファベットの連続は、横倒しの連結表示にせず、1文字ずつ縦にまっすぐ並べて表示します（B→B→Qのように縦に並びます）。タイトル・著者名にも同様に適用されます。

### ハイフンの長音記号変換

チェックボックスで ON/OFF できます。半角ハイフン `-` を長音記号 `ー` に変換します。

半角ハイフンは縦書きにしても横棒のまま回転せず表示されてしまいますが、長音記号 `ー` は縦書きで正しく縦棒として回転します。「まだか-」のように長音のつもりで半角ハイフンを使ってしまった場合の見た目崩れを防げます。

電話番号や日付など、長音以外の意味でハイフンを使っている文章では意図せず変換されてしまうため、その場合はチェックを外してください。

### 波ダッシュ・チルダの統一

波ダッシュ「〜」（U+301C）や半角チルダ「~」は、全角チルダ「～」（U+FF5E）に自動的に統一されます（チェックボックスはなく常に適用されます）。

波ダッシュ「〜」は、游明朝・MS明朝などWindowsの一部の明朝体フォントで正しいグリフを持たず、「?」として表示されてしまうことがある「波ダッシュ問題」と呼ばれる既知の不具合があるため、より広く正しく表示される全角チルダに変換しています。半角チルダ「~」も縦書きで正しく回転しないため、同様に変換されます。

### 数字の漢数字変換

チェックボックスで ON/OFF できます。半角・全角どちらの数字にも対応しています。

- `123` → `百二十三`
- `2026` → `二千二十六`
- `10000` → `一万`
- `1,234` → `千二百三十四`（桁区切りのカンマも認識）
- `3.14` → `三点一四`（小数点以下は1桁ずつ読み上げ表記）

年号（西暦）も含めて、すべて位取り表記（百二十三、二千二十六…）に統一しています。「二〇二六」のように1桁ずつ読む書き方はしていません。

### 数字の縦中横

チェックボックスで ON/OFF できます（既定は ON）。「数字を漢数字に変換する」を外して算用数字のまま書くとき、半角数字の1〜2桁を縦中横（1マスに横並びで収める表示）にします。

- `23時` の `23`、`残り5分` の `5` などが対象です。前後に数字が続く3桁以上の数字（`2026` など）は対象外で、横倒しのまま表示します
- 全角数字（`２３`）は、もともと1文字ずつ縦に並ぶので対象外です
- 縦中横にした数字は文字数カウントでも1マスとして数え、列の途中で分割しません
- タイトル・著者名にも適用されます。プレビュー上の表示のみの変換で、コピー用テキストは変わりません

### ルビ（ふりがな）

青空文庫と同じ記法に対応しています。

- `本気《マジ》` … 直前の漢字の連続に自動でルビが付きます（送り仮名は対象に含まれません）
- `｜任意の語句《よみ》` … 全角縦棒「｜」で始まりを明示すると、漢字以外（送り仮名・ひらがな・カタカナなど）を含む範囲にもルビを付けられます
  - 例: 送り仮名を含む「食べ物」全体にルビを付けたい場合は `｜食べ物《たべもの》` と書きます（`食べ物《たべもの》` だと「物」だけにルビが付きます）

pixivの小説投稿で使われる記法にも対応しています。

- `[[rb:語句>よみ]]` … 例: `[[rb:大阪>おおさか]]`（全角の`［［ ］］`・全角コロン「：」・全角矢印「＞」との混在や前後の空白も許容します）

縦書きプレビューではルビが本文の右側に正しく表示されます。「1行の文字数」の文字数カウントはルビの本文（読みではない方）の文字数だけを数え、ルビが列の途中で分断されることはありません（必ずルビごとまとめて次の列に送られます）。

入力時にどの記法を使ったかに関わらず、「ルビの出力形式」で選んだ形式に、コピー用テキスト・テキストダウンロードのルビ表記がすべて揃えられます。

- **青空文庫形式（既定）**: すべて `｜語句《よみ》` に統一されます。カクヨム・小説家になろう・青空文庫はいずれもこの記法をそのまま解釈できます。
- **pixiv形式**: すべて `[[rb:語句>よみ]]` に統一されます。pixivに投稿する場合はこちらを選んでください。

縦書きプレビューの見た目自体はどちらの設定でも変わりません（ルビの表示方法にのみ影響し、入力側の記法はどちらの形式でも常に両方受け付けます）。

### 強調（傍点）

文字の右側（縦書きの場合）に「・」のような点を打って強調する、傍点（圏点）に対応しています。

- `[[強調したい文字列]]` … 二重角括弧で囲んだ範囲に傍点が付きます
  - 例: `「[[来るまで]]車で待つか」` と書くと、「来るまで」の右側に傍点が表示されます
  - 日本語入力（IME）だと半角の`[`が全角の`［`になりやすいため、`［［強調したい文字列］］`のような全角括弧や、半角・全角が混在した括弧でも同様に認識します

コピー用テキストとテキストダウンロードでは、青空文庫の注記形式 `文字列［＃「文字列」に傍点］` に変換されます（青空文庫はもちろん、この記法を解釈できる組版ツールでもそのまま利用できます）。縦書きプレビューではCSSの`text-emphasis`機能を使って実際に傍点を描画しています。

### 濁点の強制付与

「あ」「な」「ら」など、本来濁点が付かない文字にも濁点を付けられます。叫び声や崩れた発音の表現（「あ゙あ゙あ゙」など）によく使われる技法です。

- `{{文字列}}` … 二重波括弧で囲んだ範囲の各文字に濁点（結合文字 U+3099）を付けます
  - 例: `{{あああ}}！` と書くと「あ゙あ゙あ゙！」のように表示されます
  - 全角`｛｛文字列｝｝`や、半角・全角が混在した括弧でも同様に認識します
  - 「か」「た」など元々濁点が付く文字に使うと、見た目は通常の濁音（「が」「だ」など）と変わりません

コピー用テキスト・テキストダウンロード・クリップスタジオ抽出のいずれも、実際に濁点を付けた文字に変換された状態で出力されます。1行の文字数カウントでも、濁点付きの1文字はそのまま1文字として数えます。

#### 濁点・半濁点の自動結合

チェックボックスで ON/OFF できます（既定は ON）。日本語入力で「だくてん」と打って出る「゛」（U+309B）や「゜」（U+309C）、半角の「ﾞ」「ﾟ」は独立した1文字なので、そのままだと縦書きで直前の文字と別のマスに分かれてしまいます。ON にすると、`{{ }}` の記法を使わなくても直前の文字に結合した1文字に変換します。

| 入力 | 変換後 |
|---|---|
| あ゛ | あ゙（結合濁点 U+3099 付き） |
| う゜ | う゚（結合半濁点 U+309A 付き） |
| か゛ / は゜ | が / ぱ（通常の濁音・半濁音がある組み合わせは、その文字に置き換え） |
| ｶﾞ / ｱﾞ / ﾊﾟ | ガ / ア゙ / パ（半角カタカナは全角にしてから結合） |

- 行頭や、空白・括弧などの記号の直後にある「゛」「゜」は、記号として使っているものとみなして変換しません
- 縦書きプレビュー・コピー用テキスト・テキストダウンロード・クリップスタジオ抽出（縦書き）・タイトル・著者名のすべてに適用されます
- 「゛」を記号として文字の直後に置いている文章では意図せず結合されるため、その場合はチェックを外してください

### 2段組み表示

「2段組みで表示する」にチェックを入れると、列をA4用紙1ページ分の幅ごとに区切り、さらにその中で上下2段に分けて、本のページのように枠付きで表示します（文庫本などの紙面レイアウトに近い見た目を確認したいときに使います）。

- 列の幅は実際に描画されたものを測って計算しているため、ルビの有無などで列幅が変わっても正しく折り返されます
- 「PDFとして印刷」もこのチェックの状態に連動し、ONなら印刷も2段組み（1ページ2段）、OFFなら1段（1ページ1段）で出力されます
- 「1段の列数」を指定すると、幅による自動計算の代わりに、指定した列数ごとに次の段へ進みます。空欄（自動）に戻すといつでも幅ベースの計算に戻せます
- ページ（枠）の大きさは、一番文字が多いページに合わせてすべて同じ幅・高さに揃えます。最後のページなど内容が少ないページも、空白を残したまま同じ大きさの枠で表示されます（本の各ページが同じサイズであるのと同じ考え方です。画面上のプレビューのみの調整で、PDF印刷のページサイズには影響しません）
- 1段目と2段目の間には薄い破線を引いて、段の境目がわかるようにしています。「PDFとして印刷」やHTML書き出しにもこの線は反映されます
- 画像の挿入など、本の扉ページのような装飾要素には対応していません（列を2段に分けて配置するところまでの対応です）
- 2段組みのときは、画面下の文字数欄にプレビューのページ数も表示されます

### 改ページ

チェックボックスで ON/OFF できます（既定は ON）。次の記法だけを書いた行で、次のページから始めます（前後の空白は無視します）。

- `［＃改ページ］`（青空文庫形式。半角の `[#改ページ]` も可）
- `[newpage]`（pixiv形式。全角の `［newpage］` も可）

| 表示 | 改ページの扱い |
|---|---|
| 1段組み（ページ枠なし） | 改ページの位置に破線の区切りを表示します |
| 1段組みのページ枠・2段組み・PDF印刷 | 次のページの先頭から始めます |
| ページ数の目安 | 区切られた部分ごとにページ数を切り上げて合計します |
| コピー用テキスト・テキストダウンロード | 「ルビの出力形式」に合わせた記法（青空文庫形式なら `［＃改ページ］`、pixiv形式なら `[newpage]`）に揃えます |

- 原稿の先頭・末尾にある記法や、連続した記法は1つにまとめます（空白のページは作りません）
- 文中に書いた記法（`一[newpage]二` など）は改ページにしません
- OFF にすると、記法の行も普通の本文として表示します

### 1段組みのページ枠

チェックボックスで ON/OFF できます（既定は OFF）。1段組みのとき、「1ページの行数」ごとに列を区切って、2段組みと同じような本のページの枠で表示します。

- 「1ページの行数」が空欄のとき、2段組みのときは使えません
- 文字数欄には、目安ではなく実際のページ数（枠の数）を表示します
- タイトル・著者名は、1ページ目の先頭の列として数えます
- 改ページ記法の位置で次のページへ送ります
- 「PDFとして印刷」も同じページ分けで出力します

### ページ数の目安（1段組み）

1段組みのとき「1ページの行数」を指定すると、画面下の文字数欄に「約○ページ（1ページ ○行）」と大体のページ数を表示します（空欄なら表示しません）。

- 本文の列数（縦書きの1行＝1列）を1ページの行数で割り、端数は切り上げています
- 空行も1行として数えます。原稿末尾の余分な空行もページ数に含まれるので、気になる場合は削除してください
- タイトル・著者名は扉ページなど別扱いになることが多いため数えていません
- 改ページ記法（[改ページ](#改ページ)）があれば、区切られた部分ごとに切り上げて合計します。記法を書いていない章の頭の改ページなどは考慮しないため、実際の本のページ数より少なめに出ることがあります
- 2段組みのときは使いません（入力欄が無効になります）

### クリップスタジオ ストーリーエディター形式（セリフ抽出）

原稿からセリフ行だけを抽出して、クリップスタジオのストーリーエディターなどに貼り付けやすい形にする専用欄です。縦書きプレビューには表示されません。

「クリップスタジオ形式でセリフを抽出する」にチェックを入れたときだけ欄が表示されます（未使用時は非表示のままです）。

- 抽出対象は「行の先頭（前に何も無い状態）が`「`で始まる行」のみです。ナレーション行や空行は抽出されません
- 抽出されるのは行頭の`「`から対応する`」`までの中身だけです。かぎかっこ自体は取り除かれ、`」`のあとに地の文が続く場合（例:「まだか-」と、廊下の奥から声がした。）はその地の文は含まれません
  - 傍点注記など`「」`が入れ子になっている場合（例:「来るまで［＃「来るまで」に傍点］車で待つか」）は、対応する外側の`」`を正しく判定します
- 「縦書き（変換ルールを適用）」を選ぶと、感嘆符・数字・ハイフンなど画面上部のチェックボックスで有効な変換をすべて適用した状態でセリフを抽出します（ルビ・傍点もコピー用テキストと同じ形で書き戻されます）
- 「横書き（そのまま）」を選ぶと、入力した原文のまま（変換なし）でセリフを抽出します
- 抽出した行と行の間には実際に空白行1行が入ります（クリップスタジオのストーリーエディターに貼り付けやすくするためです）。この欄を直接選択してコピーしても、「クリップボードにコピー」ボタンを使っても同じ内容になります。画面上は行間を詰めたスタイルにしているため、見た目は1行間隔に近い詰まった表示になります
- 抽出結果は一覧表示され、各行の右側にある「▲」「▼」ボタンでセリフの順番を並び替えられます。並び替えた順序は、下のコピー用テキストにもすぐ反映されます
  - 原稿を編集して再抽出されたときも、既存の行の並び順はできるだけ維持され、新しく追加された行だけが末尾に追加されます（同一内容の行が複数ある場合や、文言そのものを編集した行の並び順までは復元されません）

### 原稿ファイルとの同期（VS Code の Live Preview 使用時）

VS Code などで書いている原稿ファイルを、入力欄へ自動で流し込む機能です。ローカルサーバー経由（例: VS Code 拡張機能「Live Preview」）で `index.html` を開いているときだけ使えます。

1. `index.html` と同じフォルダに `原稿.txt`（UTF-8）を置き、原稿を書きます
2. Live Preview でプレビューを開き、「原稿ファイル（原稿.txt）と同期する」にチェックを入れます
3. `原稿.txt` を保存するたびに、約1秒以内に入力欄とプレビューへ反映されます

- ツールが読み込むのは保存済みの内容です。同梱の `.vscode/settings.json` では自動保存（入力停止から0.5秒後）を有効にしているため、書いているそばから反映されます
- 同期中は入力欄が読み取り専用になり、「一括削除」も使えません（手入力した内容が次の読み込みで上書きされて消えるのを防ぐため）。原稿は `原稿.txt` 側で編集してください
- `原稿.txt` を読み込めないとき（ファイルがない、サーバー経由で開いていない等）は、チェックの横に理由が表示され、入力欄は通常どおり編集できます
- `index.html` をダブルクリックで直接開いた場合（`file://`）は、ブラウザの制限によりこの機能は使えません
- `原稿.txt` は個人の原稿のため `.gitignore` でリポジトリから除外しています

### 出力（エクスポート）

「縦書きプレビュー」の見出し右にある3つのボタンから、変換結果をファイルとして保存できます。外部ライブラリは使わず、ブラウザ標準の機能のみで動作します。

- **テキストとしてダウンロード**: 「1行の文字数」の設定どおりに実際の改行を入れたテキストファイル（.txt）を保存します。記号・数字変換の結果を反映し、ルビは `｜本文《よみ》`、傍点は `［＃「」に傍点］` の形で書き戻されます。カクヨム・小説家になろう・青空文庫にそのまま貼り付けられます
- **HTMLとして保存**: 縦書きプレビューの見た目（CSS込み）を単体のHTMLファイルとして保存します。このツールがなくても、保存したファイルをダブルクリックするだけで同じ縦書き表示・ルビ・記号の縦中横がそのまま再現されます
- **PDFとして印刷**: ブラウザの印刷ダイアログを開きます。印刷先を「PDFに保存」にすると、入力欄などを含めず縦書きプレビュー部分だけをPDF化できます。画面上の表示範囲による制限（高さ制限・横スクロール）は印刷時には解除され、全文が出力されます。列数が多く1ページの幅に収まらない場合は、実際に描画された列の幅を測ったうえで自動的に複数ページに分割します（A4・余白1.5cm想定）。1列の文字数を極端に大きくすると、1列がページの高さに収まらないことがあります。用紙を判型サイズにしたいときは、次の「PDF印刷の用紙」を使います

### PDF印刷の用紙（判型サイズ）

「PDF印刷の用紙」で、「PDFとして印刷」の用紙サイズを選べます（既定は A4 で、従来どおりの印刷です）。

| 選択肢 | 用紙サイズ | 余白 |
|---|---|---|
| 文庫サイズ（A6） | 105×148mm | 10mm |
| 新書サイズ | 103×182mm | 10mm |
| A5判 | 148×210mm | 15mm |
| B6判 | 128×182mm | 12mm |
| B5判 | 182×257mm | 18mm |

- 1列に「1行の文字数」＋1字（ぶら下げ分）が収まるよう、文字の大きさを自動で決めます。文庫サイズ・1列40字なら、商業の文庫本に近い約9ptになります
- 1ページの列数が決まっているとき（1段組みのページ枠の「1ページの行数」、2段組みの「1段の列数」）は、その列数が用紙の横幅に収まる大きさとの小さい方にします
- 文字の大きさは最小6pxで止めます。判型に対して列数・文字数が極端に多いと、ページからはみ出すことがあります
- 「同人誌サイズ」の選択とは独立しています。「1行の文字数」を自由に変えても、用紙の選択は変わりません
- 印刷の直前に文字の大きさを切り替えてからページを分けるため、印刷ダイアログを開いている間は画面のプレビューも同じ大きさになります（印刷後に元に戻ります）
- 印刷ダイアログの用紙サイズ・余白の設定が「既定」以外になっていると、ブラウザの設定が優先されることがあります

## 開発（自動テスト）

`index.html` を [jsdom](https://github.com/jsdom/jsdom) で読み込み、変換・折り返し・禁則処理・改ページ・ページ枠・印刷用紙などを検証する自動テストを `tests/` に置いています。ツール本体は `index.html` だけで動き、テストを使わない場合は Node.js も不要です。

```sh
npm install   # 初回のみ（jsdom を入れます）
npm test
```

- Node.js 18 以上で動きます
- jsdom にはレイアウト計算がないため、実際に描画された列の幅を測る処理（幅による自動のページ分け）や見た目そのものは検証できません。列の分け方・変換結果・ページ数など「数で決まる」部分を検証しています
- テストは `window.__tategakiTest` から、入力のたびの待ち時間なしで再描画を呼んでいます（画面の動作には影響しません）

## 既知の制限

- 3文字以上連続する記号（「！！！」など）は、先頭から2文字ずつ区切って判定します。「！！！」→`!!！`、「！！！！」→`!!!!`のように、2文字に満たない端数は全角のまま残ります
- 数字と漢数字の変換は年号・数量を区別せず、すべて位取り表記で統一しています
